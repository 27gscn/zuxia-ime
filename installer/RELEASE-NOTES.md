应物足下输入法 0.27「金铃」，第一个公开版本。

Windows 上的汉字输入法，实现《应物音形汉字键入方案》：全拼承担读音，结构与部件承担字形，按固定次序拼成编码，每一级都可用，打到候选出现就可以停手。方案全文和查字页在 https://yw.rkb.pub 。

仓库里出现的 0.2 至 0.4.x 是公开之前的内部版本号。

## 装之前请先知道

- 安装包没有代码签名。Windows 会弹「已阻止此应用」或 SmartScreen 警告，这是预期的，不是安装包坏了。可以点「更多信息」→「仍要运行」；也可以先核对下面的 SHA-256；最稳的是不装现成的，fork 仓库跑一次 Actions 自己编一份。
- 原生 ARM64 程序里用不了；x64、x86 程序和模拟运行的程序可以。
- 繁体字还打不了，拆字窗里只列出繁体写法作对照。
- 拆字窗打完自动收起、繁体对照这两处只过了自动构建（编译与引擎断言），还没有在真机上验过。

核对办法（PowerShell，整块复制粘贴）：

```
Get-FileHash .\ZuxiaSetup-0.27.exe -Algorithm SHA256
```

把结果和这次发布里的 `ZuxiaSetup-0.27.exe.sha256` 比一下。

## 安装

1. 先关掉微信、Word、浏览器这些会用到输入法的程序。最稳的是先重启电脑再装。
2. 右键安装包，选「以管理员身份运行」，点「安装」。
3. 注销再登录一次（或者在「设置 → 时间和语言 → 语言和区域 → 键盘」里手动添加），然后按 `Win + 空格` 切到「应物音形足下输入法」。第一次切换会编译词库，要等十几秒。

从旧版升级时，正在运行的程序会一直用着旧版。重启电脑最省事；也可以装完双击仓库里的 `scripts/刷新足下输入法.cmd`，它会找出还在用旧版的程序，问过你之后关掉再重新打开。

## 怎么打字

一个字的码是：全拼 + 结构码 + 部件码。一个词的码是三段拼接、逐位左对齐：全拼串 + 逐位结构串 + 逐位部件串。

```
星辰  ->  xingchen  +  sb  +  rc
          全拼          结构    部件
```

星 = `xing` + `s`（上下结构）+ `r`（日）
辰 = `chen` + `b`（包围结构）+ `c`（厂）

结构码五个：`z` 左右、`s` 上下、`b` 包围、`p` 品字形及其他、`d` 独体。部件码是部件名字的拼音首字母；独体字还可以用它自己读音的首字母。

只打全拼也能出字。结构和部件是要精确定位时才加，打得越满，候选越少。

几个可以直接试的：

| 打什么 | 出什么 |
|---|---|
| `qingzs` | 清情碃 |
| `wenzswr` | 温揾 |
| `taizst` | 抬汰邰鲐 |
| `zhissmy` | 直（唯一） |
| `shuangsy` | 霜（唯一） |
| `chenbc` | 辰（唯一） |
| `chud` | 出（排第一） |
| `yuedj` | 月（唯一） |
| `yuedy` | 月乐曰，月排第一（独体字整字作部件） |
| `mingzr` | 明瞑溟暝螟 |
| `xingchensbrc` | 星辰 |

| `yinqiangzzjm` | 隐枪排第一，银枪第二 |

## 拆字窗怎么试

1. 开始菜单搜「足下输入法设置」，打开「拆字窗口（学习模式）」
2. 打 `mingyuezdry`：拆字窗显示「明」「月」两个字，每个部件一行，最后一行不被截掉
3. 拖它、拖边角、滚轮、双击标题条：窗口不该消失，打字的光标不该跑到它身上
4. 按空格上屏：拆字窗换成刚上屏的「明月」，两秒后自己收起；这两秒里点它一下，它就留着，鼠标移开两秒后再收
5. 再打一个字，点拆字窗的 ×：这次组字里它不再出来；落字后再打下一个字，它应该自动回来
6. 关掉它所在的程序、切到别的程序：它应该自己隐藏
7. 有两块屏幕的话：把它拖到另一块屏上放手，它应该留在那块屏上；再打字，它还在那里出现
8. 打 `yinzjg`：「银」右边一个小格「銀」，上面写「繁体」；打 `fa`：「发」右边两个小格「發」「髮」，上面写「繁体 · 按词义选用」

## 最想知道的

1. 这套规则好不好学、好不好猜。猜不中的结构码请具体说是哪个字
2. 部件码够不够用：有没有哪个字，你想到的拆法打不出来
3. 拆字窗：上面 8 步哪一步对不上
4. 有没有丢字：打过的键没进去，或者选了候选之后剩下的码不见了
5. 有没有崩溃，或者某个程序里不好用（尤其是 Office、浏览器、微信、终端）

## 出问题了怎么说

到 [Issues](https://github.com/27gscn/zuxia-ime/issues) 提，一个问题一条，请附上 `%LOCALAPPDATA%\Zuxia\zuxia.log`。它只记事件，不记你打了什么字：打过的码、选过的候选、落下的文本，一个字都不在里面。

文件资源管理器地址栏里粘这个就能找到：

```
%LOCALAPPDATA%\Zuxia
```

## 卸载

在「设置 → 应用 → 已安装的应用」里正常卸载，或者运行安装目录里的 `ZuxiaUninstall.exe`。

卸载默认留下 `%LOCALAPPDATA%\Zuxia`（约 15 MB：用户词典、回流表、日志、设置），这样重装之后调频和自造词还在。要彻底清干净，卸载完手动删掉那个文件夹。
